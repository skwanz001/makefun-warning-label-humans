One line of comedy: the safety warning label that should come printed on
every human being — entered in make.fun's "Warning Label for Humans: One
Line, Big Laugh" bounty. `main.py` (standard library only) writes the
label to `/output/entry.txt`.

The label, 122 characters:

> WARNING: This unit reads the first two lines of the manual, declares itself an expert, and immediately voids the warranty.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

Written like a real printed label ("This unit ..."), the joke is
recognition — everyone has skimmed a manual and felt like an expert —
and the laugh lands in the last few words ("immediately voids the
warranty").
